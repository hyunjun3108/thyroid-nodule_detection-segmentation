# 석사학위논문 LaTeX 원고

갑상선 결절 초음파 영상의 경량 검출·분할 모델 (추론 비용 없는 경계 정교화 모듈과 INT8 양자화를 중심으로)

## 컴파일

- **XeLaTeX로 컴파일한다.** 한글 때문에 pdfLaTeX로는 되지 않는다. LuaLaTeX도 동작한다.
  `main.tex` 첫 줄의 `% !TEX program = xelatex`와 `latexmkrc`가 대부분의 편집기(Overleaf 포함)에서 이를 자동으로 지정한다.
- 순서는 XeLaTeX → BibTeX → XeLaTeX × 2이며, latexmk를 쓰면 알아서 처리된다.
- 한글 글꼴은 설치된 것 중에서 Noto Serif CJK KR → 나눔명조 → 은바탕 순으로 자동 선택된다.
  셋 다 없는 환경이면 `settings.tex`의 글꼴 이름을 그 환경에 있는 한글 글꼴로 바꾼다.
- 다른 곳에서 편집하려면 `python scripts/make_thesis.py --zip`으로 만든 `thesis_source.zip`을 올리면 된다.
  압축을 풀면 `thesis/` 폴더 하나가 나오고 그 안의 `main.tex`가 주 파일이다.

## 직접 채울 곳

`main.tex` 상단의 논문 정보 블록만 고치면 표지·인준지·초록에 모두 반영된다. 빨간 글씨로 표시된다.

- 저자명(국문·영문), 지도교수, 대학교·학과(국문·영문), 제출일, 학위 수여일
- 국문·영문 초록 마지막 줄의 학번
- 표지와 인준지는 일반적인 양식으로 만들었다. 학교 양식이 정해져 있으면 `front/cover.tex`, `front/approval.tex`를 교체한다.

## 폴더 구성

| 경로 | 내용 | 직접 수정 |
|---|---|---|
| `main.tex` | 문서 틀과 논문 정보 | O |
| `settings.tex` | 글꼴·여백·장 제목 등 서식 | O |
| `front/` | 표지, 인준지, 국문 초록 | O |
| `chapters/` | 제1~7장 본문 | O |
| `back/` | 부록, 영문 초록 | O |
| `refs.bib` | 참고문헌 (인용된 것만 목록에 실림) | O |
| `tables/` | 표 15개 — **실험 결과에서 자동 생성** | X |
| `figures/` | 그림 13개 (벡터 PDF) — **자동 복사** | X |

`tables/`와 `figures/`는 연구 저장소의 `scripts/make_thesis.py`가 실험 결과 파일(csv/json)에서 만든다.
실험을 다시 돌려 수치가 바뀌면 그 스크립트를 다시 실행하면 표가 따라 갱신된다. 이 두 폴더의 파일을 직접 고치면
다음 생성 때 덮어써지므로, 표 내용을 바꾸려면 스크립트를 고친다. 본문의 수치는 표와 일치하도록 손으로 쓴 것이므로,
결과가 바뀌면 본문도 함께 확인해야 한다.

## 원고를 고칠 때 유지해야 할 결론

아래는 실험 결과에서 확정된 결론이다. 문장을 고치는 과정에서 이 내용이 바뀌지 않았는지 확인할 것.

1. **교차 데이터셋 결과는 "악화"가 아니라 "판정할 수 없다"이다.** 시드 42 하나만 보면 크게 나빠진 것처럼 보이지만,
   3시드 기준으로는 개선도 악화도 유의하지 않다(시드 단위 p = 0.073–0.999).
2. **경계 손실 계수(g=1.0, λ=2.0)는 held-out 결과로 골랐다.** 검증 분할로 다시 보면 경계 정교화 효과 자체는 모든 구성에서
   재현되지만, 채택한 구성의 우위는 재현되지 않는다. 따라서 최종 개선 폭은 낙관적일 수 있다(5.5절, 6.6절). 이 단서를 지우면 안 된다.
3. **fold 단위 검정의 "유의하지 않음"은 검정력 한계이다.** n=5에서 양측 Wilcoxon의 최소 p가 0.0625이다.
4. **영상 단위 p값을 교차 데이터셋의 근거로 쓰면 안 된다.** 그것은 학습된 특정 모델에 대한 진술이다.
5. **ONNX Runtime INT8은 가설 H3을 충족하지 못했다.** H3은 OpenVINO 경로에서만 지지된다.
6. **양자화 붕괴 원인과 ONNX의 mAP 하락 원인은 '추정'이다.** 확인된 사실처럼 고쳐 쓰지 말 것.

## 제출 전에 확인할 것

- **참고문헌**: `refs.bib`의 서지 정보는 원문과 대조하지 않았다. Zotero 등으로 DOI·쪽수를 확인하고 학과 양식(번호식/저자-연도식)에 맞출 것.
  저자-연도식이 필요하면 `main.tex`의 `\bibliographystyle{unsrtnat}`를 `plainnat`으로, `settings.tex`의 natbib 옵션 `numbers`를 `authoryear`로 바꾼다.
- **임상 배경 수치**(결절 발견율 19–68%, 악성 7–15%, TI-RADS 경계 점수)는 인용한 지침서 원문과 다시 대조할 것.

## 로컬에서 컴파일하기

```bash
# TeX Live가 있는 경우
latexmk main.tex            # latexmkrc 가 XeLaTeX 를 지정한다

# TeX Live 없이
tectonic -X compile main.tex
```
